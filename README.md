# PS4 Battery

Windows 系统托盘工具，通过 HID 读取 Sony DualShock 4 手柄电量，支持电量提醒、灯条控制和可编辑电量颜色曲线。

## 功能

- 支持原装 DualShock 4 一代 / 二代，蓝牙或 USB 连接；读取第一只可访问的手柄。
- 托盘数字显示电量区间下限，例如 `20` 表示 **20–29%**。悬停查看完整状态，双击打开设置。
- 持续读取报告，每秒更新界面，断线后每 3 秒重试。约 5 秒没有新数据时不再显示旧电量。
- 低电量阈值按 10% 设置，默认低于 20% 提醒、低于 10% 再提醒。充电时不提醒，同一轮放电不重复弹窗。
- 灯条模式：固定颜色、按低电量阈值变色、关闭、电量渐变曲线。
- 颜色曲线支持 2–16 个节点，拖动电量位置、自选颜色、添加及删除节点，节点之间按 RGB 线性插值。
- 模拟电量滑块与可选手柄预览；离开曲线页、关闭窗口或应用设置后恢复真实电量控制。电量提醒不受模拟值影响。
- 渐变模式跨档约 0.6 秒平滑过渡，充电时优先显示充电颜色。
- 可选登录 Windows 后自动运行，启动到托盘，不弹出设置窗口。

## 构建与运行

需要 Windows 和 **.NET 8 SDK** 来构建；运行需要 **.NET 8 Desktop Runtime**。不依赖第三方 NuGet 包。

在 PowerShell 中执行：

```powershell
.\Build.ps1
```

也可以手动构建：

```powershell
dotnet publish PS4Battery.csproj -c Release -o app
```

然后双击 `Start.cmd`，或启动 `app\PS4Battery.exe`。若图标位于任务栏折叠区，可将其拖到常显区域。

右键图标可切换灯条模式、开关提醒、测试通知或退出。关闭设置窗口后程序继续驻留托盘。

## 设置

| 标签 | 内容 |
| --- | --- |
| 常规 | 登录当前 Windows 账户后自动运行 |
| 状态 | 真实电量、连接、报告时间和灯条发送结果 |
| 灯条 | 模式、固定颜色，以及正常 / 低电量 / 充电颜色 |
| 颜色曲线 | 节点编辑、模拟电量、手柄预览 |
| 电量提醒 | 提醒开关、两级阈值、测试通知 |

点击“应用”保存并生效。配置存放在可执行文件旁的 `settings.json`，应将程序放在当前用户可写的目录。个人配置不包含在仓库中。

默认曲线：**0% 红 → 20% 橙 → 50% 黄 → 100% 绿**。0% 和 100% 端点可改色，但不能移动或删除。节点不能交叉、重叠。点击“使用此曲线作为灯条模式”，再点“应用”启用。

自动运行只管理当前用户注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `PS4BatteryTray` 项，默认不启用。取消勾选并应用即可移除。若 Windows 的启动应用设置禁用了该项，需要在那里重新启用；移动程序后重新设置以更新路径。

## 数据与兼容性

- 手柄提供约 10% 一档的估算电量，而非精确百分比。充电中也使用手柄自身报告，100% 与“已充满”分别处理。
- 曲线按报告区间下限取色，例如 20–29% 使用 20% 的颜色。模拟滑块的 1% 步进不会提高真实测量精度。
- 共享读取实体 HID 设备，不安装驱动、不改变按键映射。灯条输出只设置颜色和闪烁标志，不设置震动。
- 必要时读取 `0x02` 功能报告以请求蓝牙完整数据；会改变手柄报告模式，断开重连可恢复。
- HidHide、独占访问及部分第三方手柄可能使电量不可用。Steam / DS4Windows 可能覆盖灯色；本程序在目标颜色变化或重连时发送，并在首次成功写入后的第 1、3、6、10 秒有限补发；默认还会每 5 秒重新应用当前颜色，间隔可在灯条页设置为 1–60 秒；可在灯条页关闭保持选项。多个程序同时控制灯条时，请选择一个控制来源以避免颜色来回变化。
- 灯条输出失败时显示原因并重试；退出程序不会恢复原先灯色。Windows 勿扰模式可能隐藏提醒。

## 验证

`Build.ps1` 会运行协议解析和逻辑自检，检查 CRC、Windows 填充报告、电量状态、提醒阈值、渐变插值、节点合法性、配置序列化及输出报文。结果写入 `app\test-result.txt`。

其他诊断参数：

| 参数 | 用途 |
| --- | --- |
| `--settings` | 启动并打开设置窗口；已有实例时不重复启动 |
| `--self-test` | 不访问设备，运行逻辑自检后退出 |
| `--smoke-test` | 运行托盘约 8 秒，记录状态到 `smoke-result.txt` 后退出；请先退出常驻实例 |
| `--startup-test` | 测试注册启动项和移除，最后恢复原值；会临时修改当前用户启动项 |

已在蓝牙 DualShock 4 二代上验证电量和充电读取、灯条输出、曲线编辑、模拟预览及恢复、配置保存、启动项启用/移除。USB 分支经过逻辑检查，未进行实机验证；未通过实际放电跨阈值验证通知，亦未通过重启 Windows 验证登录自启。

## 打包便携发布版

运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Package.ps1`。
脚本按项目版本号生成 Windows x64 自包含 ZIP 和 SHA256 校验文件，输出到 `artifacts/`。
包内含 .NET Desktop 运行环境，解压后直接运行 `PS4Battery.exe`；不需要 `Start.cmd`。
打包前运行逻辑自检，不携带个人设置、诊断输出或调试符号。首次构建需要联网下载官方运行时包。

灯条刷新间隔只控制定时补发；电量变化仍会更新目标颜色，界面仍每秒刷新。修改后点击应用即可生效，无需重启。
